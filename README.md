# Skillence Review\n\nResponsive student feedback frontend for Skillence Academy.\n\n## Setup\n\nDeploy to Vercel as a static site. Configure `config.js` with a Supabase project URL and **publishable/anon key only** once a secure `skillence_reviews` table with INSERT-only RLS policy is created. Never put service-role or secret keys in public frontend code. Until then, the page clearly operates as a frontend preview.\n\nFields: name, course, 1–5 stars, feedback, optional mobile and explicit publishing consent. Do not publish phone numbers.\n
